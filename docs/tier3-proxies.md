## KCCI/KDCI 수집기 (다음 스프린트 후보)
공공데이터포털 파일데이터 또는 국가물류통합정보센터 엑셀 다운로드 기반 주간 수집기.
주간·파일 형식이라 기존 일간 JSON 수집기와 패턴이 달라 별도 작업으로 분리. 지표 등록 시
해상운임 노드(해도)와 매핑하면 호르무즈·홍해 시나리오의 조기신호 슬롯이 채워진다.
그때까지는 KOBC 발표(매주 월 14시)를 수동 참조.

## 원칙 재확인
실현변동성 프록시 2종은 **새 외부 의존성 제로** — 이미 수집 중인 시계열의 파생이라
소스 단절 리스크가 없다. 프록시가 원지표와 다르게 움직이는 국면(예: MOVE는 옵션 내재변동성,
프록시는 실현변동성이라 위기 직전 내재만 튀는 구간을 못 잡음)이 있음을 노브 문장에 명시했다.
